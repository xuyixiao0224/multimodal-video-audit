## 📦 快速开始

### 步骤1: 安装Streamlit

```bash
# 激活虚拟环境（如果需要）
source venv/bin/activate  # macOS/Linux
# 或
venv\Scripts\activate     # Windows

# 安装Streamlit
pip install streamlit
```

**验证安装**:```bash
streamlit --version
# 应该显示类似: Streamlit, version 1.29.0
```

---

### 步骤2: 运行Web应用

```bash
# 在项目根目录执行
streamlit run web_interface.py
```

**或使用Python直接运行**:
```bash
python -m streamlit run web_interface.py
```

**首次运行**: 浏览器会自动打开 `http://localhost:8501`

**手动访问**: 如果浏览器没有自动打开，在浏览器中访问:
```
http://localhost:8501
```

## 📝 使用步骤详解

### 步骤1: 配置API（首次使用）

**位置**: 左侧边栏 → ⚙️ 配置 → API配置

1. **输入API Key**
   - 字段: `API Key`
   - 格式: `sk-xxxxxxxxxxxxxxxxxxx`
   - 类型: 密码字段（显示为••••）
   - 默认: 自动读取 `src/config.py` 中的配置

2. **选择模型**
   - 字段: `模型名称`
   - 默认: `qwen3-omni-flash`
   - 可修改: 支持其他兼容的模型

3. **保存配置**
   - 配置会自动保存在会话中
   - 刷新页面后需要重新输入API Key

---

### 步骤2: 上传视频文件

**位置**: 主界面 → 📤 上传视频

**操作**:
1. 点击"**Browse files**"按钮
2. 或**拖拽**视频文件到上传区域
3. 支持**多个文件**同时上传

**支持的格式**:
- ✅ MP4 (推荐)
- ✅ MOV
- ✅ AVI
- ✅ MKV
- ✅ WMV

**文件大小限制**:
- Streamlit默认: 200MB

```bash
streamlit run web_interface.py --server.maxUploadSize=1000
# 设置为1000MB
```

### 步骤3: 调整分析配置（可选）

**位置**: 左侧边栏 → ⚙️ 配置 → 分析配置

#### 切片时长

**说明**: 每个视频切片的时长

**默认值**: `120 秒` (2分钟)

**调整范围**:
- 最小: 30秒
- 最大: 300秒 (5分钟)
- 步长: 30秒

**推荐值**:
- 🎓 教育视频: 120-180秒
- 🎬 短视频: 60-90秒
- 🎥 长视频: 180-240秒

#### 重叠时长

**说明**: 相邻切片的时间重叠，防止边界遗漏

**默认值**: `20 秒`

**调整范围**:
- 最小: 0秒（无重叠）
- 最大: 60秒
- 步长: 5秒

**推荐值**:
- 一般场景: 15-20秒
- 高精度要求: 25-30秒
- 快速分析: 10秒

#### 高级选项

**启用方式**: 勾选"显示高级选项"

1. **最大Token数**
   - 默认: 2048
   - 范围: 512-4096
   - 作用: 限制AI单次输出长度

2. **Temperature**
   - 默认: 0.2
   - 范围: 0.0-1.0
   - 作用: 控制AI输出的随机性
   - 推荐: 保持0.2（稳定性与灵活性的平衡）

## 🔧 故障排除

### 问题1: ModuleNotFoundError: No module named 'streamlit'

**原因**: Streamlit未安装

**解决**:
```bash
pip install streamlit
```

### 问题2: API Key无效

**症状**:
```
❌ 请配置有效的API Key！
```

**原因**:
- API Key格式错误
- API Key已过期
- 未配置API Key

**解决**:
1. 检查API Key是否包含"sk-"前缀
2. 登录阿里云百炼平台获取有效Key
3. 在侧边栏输入正确的API Key

### 问题3: 视频上传失败

**症状**: 文件无法选择或上传

**原因**:
- 文件格式不支持
- 文件过大
- 浏览器兼容性问题

**解决**:
1. 转换为MP4格式
2. 减小文件大小（压缩至720p）
3. 使用Chrome/Firefox浏览器

### 问题4: AI分析超时

**症状**: 卡在"AI分析中..."超过2分钟

**原因**:
- 视频切片过大
- 网络连接问题
- AI服务响应慢

**解决**:
1. 减小切片时长（120→90秒）
2. 检查网络连接
3. 查看阿里云DashScope服务状态

### 问题5: 结果为空（无错误）

**症状**: 所有视频都显示"无错误"

**可能原因**:
1. 视频确实无质量问题
2. AI模型未正确识别（需调整prompt）
3. 视频格式不支持

**验证方法**:
1. 使用测试视频（已知有问题）
2. 检查日志输出
3. 查看AI原始响应

## 📊 性能优化建议

### 1. 并发分析

**优化**: 同时分析多个切片

**实现**:
```python
# 使用ThreadPoolExecutor并行处理
from concurrent.futures import ThreadPoolExecutor

with ThreadPoolExecutor(max_workers=3) as executor:
    futures = [executor.submit(analyze_single_video, path) for path in video_paths]
    results = [f.result() for f in futures]

@st.cache_data
def analyze_video_cached(video_path, system_prompt):

## 🔐 安全性考虑

### 1. API Key保护

**问题**: API Key在内存中存储

**解决**:
- 使用 `st.secrets` 管理敏感信息
- 创建 `.streamlit/secrets.toml`

```toml
# .streamlit/secrets.toml
[api]
key = "sk-your-api-key-here"
```

**使用**:
```python
api_key = st.secrets["api"]["key"]
```

### 2. 文件安全

**临时文件**: 上传到临时目录，分析后自动清理

**清理逻辑**:
```python
# 分析完成后清理
def cleanup_temp_files(video_paths):
    for video_path in video_paths:
        temp_dir = os.path.dirname(video_path)
        if os.path.exists(temp_dir):
            shutil.rmtree(temp_dir)
```

### 3. 会话隔离

**特点**: 每个用户会话相互独立

**影响**:
- A用户的上传文件B用户无法访问
- API Key在不同会话中隔离
- 结果数据会话结束自动清理

## 📋 命令备忘

**启动Web应用**:
```bash
streamlit run web_interface.py
```

**指定端口**:
```bash
streamlit run web_interface.py --server.port 8888
```

**指定地址**:
```bash
streamlit run web_interface.py --server.address 0.0.0.0
```

**调试模式**:
```bash
streamlit run web_interface.py --logger.level debug
```

**无浏览器模式**:
```bash
streamlit run web_interface.py --server.headless true
```
